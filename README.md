# CHARM website

React + Vite + Tailwind 3. Edit `src/site.config.js` for all content and links. Empty links are hidden.

```
npm install
npm run dev
```

Deploy on Vercel or Cloudflare Pages (build `npm run build`, output `dist`). Set `VITE_SITE_URL` to your domain.
Replace `public/logo.png` and `public/og.png` (or og.jpg) with your own. See POLYGONSCAN_UPDATE.md.
